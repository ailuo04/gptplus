# 自定义生图插件设计（2026-11-04）

## 已确认目标
在 gpt++ 插件市场安装和配置自定义生图；用户填写 OpenAI 兼容 Images API 的 Base URL（或完整 generations 端点）、API Key、模型。启用后安装用户级 gptplus-imagegen 技能。默认优先选项通过受管理的 skills.config 条目停用内置 imagegen 技能；不宣称关闭底层工具或保证自然语言自动匹配。

## 组件和数据流
- plugin-manager 注册插件并规范化配置；公开状态只返回 hasKey，不返回密钥。
- store 使用现有系统安全存储加密生图凭据，读写失败不得退化为明文。
- image-generation 执行固定配置的 Images API 请求，校验输入、限制响应大小、超时、不重试或切换提供商。生成图片支持 b64_json 和无鉴权 URL 下载。
- 网关增加仅本机且需网关令牌认证的生图路由。模型、URL、Key 由主进程配置决定，调用者不能覆盖。
- imagegen-skill 安装无凭据的 SKILL.md、Python 标准库执行脚本和仅含本地配置路径的定位文件；脚本经本地网关生成图片并非覆盖式保存。
- 用户启用/设置默认时备份 Codex 配置并写入有校验标记的技能开关；停用和卸载禁用专用技能、撤回内置技能开关，保留插件配置。配置或已安装技能被外部修改时拒绝覆盖。失败时回退本次变更。
- UI 显示配置入口、设为默认选项、固定路由验证按钮（实际生成一张图片、明确计费）、技能配置状态、重启提示及非强制接管边界。

## 约束
不新增依赖、不提交或推送、不修改用户现有全局配置；只有用户在应用中启用插件时才修改 Codex 用户配置。不修改其他插件、提供商复制 Key 功能或已有未跟踪文件。首版支持文生图，不把编辑请求假装生成请求执行。Python 3 由客户端可用运行时提供，不自动安装。

## 验证
隔离临时目录测试加密持久化/无明文广播、真实本机 HTTP 固定路由和认证、失败不回退、技能开关冲突及恢复、IPC 事务、renderer 配置表单和明确状态。执行完整 npm test、语法检查和隔离 Electron 冒烟测试；不使用真实 API Key、不触发真实付费生图。新会话模型自动选择的实机效果未验证时明确报告。

## 用户补充：生成参数
允许配置与按请求覆盖尺寸 1K/2K/4K、比例 1:1/4:3/3:4/16:9/9:16、画质 low/medium/high/auto、背景 auto/opaque/transparent。默认值为 1K、1:1、auto、auto。尺寸按长边 1024/2048/4096 px 换算并在 UI 显示实际宽高；不声称任何特定提供商一定支持。透明背景指定 PNG。未指定参数沿用保存值，服务拒绝时不自动降低配置。

## 用户补充：单次参数作用域
插件保存值仅作为默认值；本次明确指定的字段覆盖且仅覆盖该次请求，其他字段仍用默认值。执行器不保存本次参数、不维护会话级覆盖状态；后续请求、其他对话与并发请求均不受影响。技能只有在当前请求明确要求复用上次参数时才引用前次设置；普通内容或风格续作不意味着继承分辨率、比例、画质和背景。
