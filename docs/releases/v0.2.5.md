# gpt++ v0.2.5

## 更新内容

- 收敛界面按钮、窗口与卡片配色，降低高饱和渐变和发光效果，让控件与窗口表面更协调。
- 重排使用量页面：Token 趋势与模型/提供商统计并排展示，请求记录改为卡片内滚动，减少页面纵向溢出。
- 压缩桌面端请求表格列宽，让 Token 和状态列在常规窗口内完整可见；窄窗口仍保留横向滚动。
- 为上游网络模式加入独立语义色：系统代理使用蓝色，直连使用琥珀色，选中状态和标签同步变化。
- 修复默认模型下拉菜单被下方模型表格遮挡的问题，并确保菜单背景不透明。

## 验证

- 全量测试：171 项，170 项通过，1 项按现有真实配置条件跳过，0 项失败。
- Electron 浅色主题模型页与使用量页截图验证通过，启动冒烟检查通过。
- GitHub Actions 将在推送 `v0.2.5` 标签后构建 Windows 安装包并创建 Release。

## 安装包

GitHub Actions 会自动将 Windows 安装器、差分 blockmap 和 `latest.yml` 上传到本次 Release。
