# gpt++ v1.6.7

## 软件内更新摘要

- 用量状态栏速度改为首包后的生成速度，与中转控制台正常样本保持一致。
- 正常请求不再被整次请求等待时间拉低，速度可直接和上游面板对照。
- 缓冲流产生的上千 `tok/s` 异常值会被过滤，不再回退成另一套估算口径。

## 更新内容

### 修复：生成速度与中转控制台对齐

- 速度公式改为“输出 Token /（总耗时 - 首包耗时）”，不再使用包含排队与首包等待的整请求平均速度。
- 首包时间覆盖思考、正文和工具参数的第一个输出片段，兼容 Chat Completions、Anthropic Messages 和 Responses 协议。
- 使用多组真实请求与上游面板数据验证，正常样本差异控制在取整误差范围内。

### 修复：丢弃失真的缓冲流速度

- 缺少首包时间、有效生成时间不足 `50ms` 或结果达到 `600 tok/s` 时，不再记录速度。
- 明确不可用的速度不会再回退到 rollout 估算，状态栏直接显示暂无可靠速度，避免混用统计口径。
- 用量信息栏文案改为“首包后生成速度”，说明不包含排队与首包等待。

## 兼容性

- 提供商、API Key、模型、注入状态、用量历史和插件配置无需迁移。
- 所有模型与三类入站、三类上游协议继续使用同一套 Usage 归一化与状态栏展示逻辑。
- GitHub Release 继续提供 Windows x64 NSIS 安装器、差分 `blockmap` 和 `latest.yml` 更新元数据。
