# gpt++ v1.2.4

## 更新内容

### 修复重启 ChatGPT 后出现“文档图标”的客户端

- 重启不再直接运行 WindowsApps 包内的 `ChatGPT.exe`。直接运行会丢失 MSIX 包身份，任务栏会退化成通用文档图标，客户端也可能拿不到包内资源。
- 新流程：解析实际安装位置 → 解析 Windows 应用入口（AUMID）→ 结束旧进程并等待退出 → 通过 `explorer.exe shell:AppsFolder\<AUMID>` 激活 → 轮询确认新的 ChatGPT 进程出现。
- AUMID 解析有三路兜底：`Get-AppxPackage` + 包清单、直接读取安装目录的 `AppxManifest.xml`、`Get-StartApps` 按同包族匹配。本机实测可解析出 `OpenAI.Codex_2p2nqsd0c76g0!App`。
- 结束和校验进程时使用实际解析到的 exe 文件名，不再写死 `ChatGPT.exe`。
- 包安装场景解析不到应用入口时直接报错，不会退回直接运行 exe；并且会先确认入口再结束旧进程，解析失败不会先把用户正在用的 ChatGPT 关掉。

### 兼容不同电脑和不同安装位置

- ChatGPT 安装位置不再依赖固定盘符、用户名或版本目录：
  - `Get-AppxPackage` 返回的实际 `InstallLocation`；
  - `WindowsApps` 目录扫描（`Get-AppxPackage` 不可用时）；
  - 常见独立安装目录（`%LOCALAPPDATA%\Programs\ChatGPT`、`%ProgramFiles%\ChatGPT` 等）；
  - 仍找不到时，重启动作会弹出文件选择框，选择结果保存在当前用户配置中。
- 支持 MSIX 包安装在非系统盘、包根目录或 `app` 子目录；手动选择不同名称的客户端 exe 后，结束和校验也会跟随实际文件名。
- 非 MSIX 独立安装仍可直接启动，启动时把工作目录设为 exe 所在目录。

### 修复“点击重启后红色警示不消失”

- 确认重启后立即撤下红色“配置待生效”警示，按钮进入“正在重启 ChatGPT…”并禁用，不再等主进程结束和拉起完成。
- 重启失败时恢复红色警示并显示具体原因；成功后同步刷新设置页的待重启提示。
- 迟到的旧 Codex 写入状态广播不会再把红色重新标回来。

### 开机自启动更可靠

- 登录后仍通过 Windows 应用入口激活真正的 ChatGPT 主窗口，不结束已有客户端。
- exe 解析失败会重试一次；启动后会轮询确认 ChatGPT 进程出现，失败重试一次并记录 warn 日志。
- 日志增加 exe 路径、AUMID 和 PID，便于在其它电脑排查。

### 模型拖动排序修复

- 拖动预览的让位顺序与松手后提交的顺序一致，不再出现“看着已换位、松手又弹回”。
- 被拖行中心越过格边界即换位，拖半行即可移动。
- 拖出表格、窗口失焦或页面重绘时会自动收尾，不会留下卡死的拖拽状态导致之后拖不动。
- 松手时同步最终指针位置并立即更新 DOM 顺序。

## 验证

- 全量 Node 测试：231 项通过、0 项失败、1 项跳过（真实 `config.toml` 当前处于注入状态，跳过逐字还原比对）。
- 新增 ChatGPT 发现、重启与登录启动用例：16 项安装发现、28 项启动与重启、9 项登录自启动。
- 渲染层 64 项通过，覆盖重启红色状态、模型拖动顺序与页面重绘后的拖拽恢复。
- 真机验证：`Get-AppxPackage` 不可用时可通过本地 `AppxManifest.xml` 解析出 `OpenAI.Codex_2p2nqsd0c76g0!App`；重启日志确认通过应用入口拉起并检测到新进程。

## 安装与升级

- Release 提供 Windows x64 NSIS 安装器、差分更新 blockmap 和自动更新元数据 `latest.yml`。
- 沿用仓库现有未签名构建流程，Windows 可能显示“未知发布者”或 SmartScreen 提示。
- 升级不清空用户配置、提供商、API Key 或历史使用量数据。
- 如果之前手动选择过 ChatGPT.exe，该路径会保留；自动发现失败时可在重启时重新选择。
