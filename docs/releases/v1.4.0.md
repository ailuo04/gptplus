# gpt++ v1.4.0

## 更新内容

### 新增：微信连接（替代 QQ 远程助手）

用个人微信直接连接本机 Codex，不再需要 NapCat、OneBot 或公网地址：

- **扫码登录**：微信连接页发起扫码，手机确认后自动保存凭据、账号和 iLink 地址；凭据只保存在当前用户的 `~/.gptplus`。
- **每个联系人独立会话**：每个微信联系人映射到一个独立的 Codex app-server thread，在微信里发消息即可让 Codex 在设定工作目录中执行并回复；重新连接后会尽量恢复原会话。
- **连接设置**：支持联系人白名单、工作目录、回答模型、沙箱权限（只读 / 允许修改工作目录 / 完全访问）和 Codex CLI 路径。
- **微信指令**：发送「帮助」查看指令；「新对话」清空当前联系人的上下文；「状态」查看连接、账号、工作目录、模型和会话信息。指令不启动 Codex，也不消耗模型调用。
- **图片双向收发**：微信图片会保存到本机媒体目录并作为 Codex 图片输入（单条最多 4 张、单张 5MB）；本次回合在工作目录内新生成或修改的图片会自动回传微信（最多 3 张、单张 10MB，需要沙箱可写）。
- **任务通知**：ChatGPT 桌面任务开始、完成、失败、停止时即时发到微信，运行中每 5 分钟提醒一次；通知直接发送，不进入 Codex 上下文。
- **升级迁移**：旧 QQ 助手的 `workspaceDir` 和 `codexPath` 会迁移到微信连接；QQ / NapCat 相关配置不再生效。QQ 远程页、NapCat 一键安装、OneBot 上报接口和相关模块已移除。

### 新增：插件市场

- 侧栏新增「插件市场」，集中安装、卸载、启用、停用和配置随 gpt++ 发布的内置插件。
- 当前包含两个插件：**微信连接** 与 **ChatGPT 用量信息栏**；安装状态写入本机配置，重新安装后需要重新启用。
- 插件启停会联动运行时：停用或卸载微信连接会停止长轮询和 app-server；启用后按配置自动恢复。
- 未安装微信连接插件时隐藏微信连接入口；已安装数量显示在侧栏徽标上。

### 新增：ChatGPT 用量信息栏

- 在 ChatGPT 输入框下方显示**生成速度（tok/s）**、**缓存命中率**和**上下文占用环**，并按会话切换显示对应数据。
- 数据来自本机 Codex 会话记录的尾部 Token 统计，只读取用量字段，不读取消息正文；页面通过 gpt++ 推送数据，不直接访问本地网关。
- 支持在插件配置里单独关闭某项指标；页面重载或切换会话后自动重新挂载，gpt++ 重启后也会尝试接回仍在运行的 ChatGPT。
- 原 gpt++ 窗口底部的「最近请求指标」已移除，避免同一组数据在应用内重复展示。
- 重启 ChatGPT 时通过 CDP 调试端口注入；注入失败会单独提示，不影响客户端已经启动的事实。停用量信息栏插件后不再带调试端口启动 ChatGPT。

### 安全：网关令牌不再写入 Codex 配置

- `[model_providers.gptplus]` 改用 `auth.command`：Codex 只在需要时从 `~/.gptplus/config.json` 读取当前网关令牌，令牌不再以 `experimental_bearer_token` 明文写入 `~/.codex/config.toml`。
- 移除了内置的固定回退令牌；网关令牌为空时不会再用通用值兜底。
- 网关日志、错误诊断与崩溃报告继续脱敏，并把微信凭据纳入脱敏范围。

### 网关与任务观察

- 新增 `/thread-usage-live` 本机会话用量接口，需要网关 Bearer 令牌，仅该路由开放状态栏所需的 CORS。
- 任务观察改为独立的任务监听器：只跟踪经过本地网关、且不是微信来源的 ChatGPT 桌面轮次，避免微信对话和远端共享流量产生重复通知。
- 微信来源请求可通过 `X-Gptplus-Source: weixin` / `originator` 标记；网关只把 `~/.gptplus/weixin-media/` 白名单目录内的 `file://` 图片转成 data URL，拒绝目录外文件和符号链接。
- 移除 `/onebot/event` 上报路由与 NapCat 相关代码。

### 界面与交互

- 侧栏由「QQ 远程」改为「插件市场」+「微信连接」；页面文案、状态芯片和操作按钮按新连接方式重做。
- 微信连接页提供状态卡、扫码弹窗、联系人/消息统计、连接设置和运行日志。
- 设置页访问令牌说明更新为「认证命令按需读取，不写入 Codex 配置」。

## 验证

- 全量 Node 测试：316 项、315 项通过、0 项失败、1 项按真实用户配置条件跳过。
- Electron 冒烟渲染：主页、插件市场、微信连接页均无运行期错误；已人工核对三页截图。
- 覆盖微信文本/图片收发、AES 图片加解密、每联系人会话、扫码登录、任务通知、插件生命周期、用量读取、状态栏注入与 app-server 协议。
- Windows x64 NSIS 未签名构建通过；Release 会同时上传安装器、`blockmap` 和 `latest.yml`。

## 安装与升级

- Release 提供 Windows x64 NSIS 安装器、差分更新 `blockmap` 和自动更新元数据 `latest.yml`。
- 本版本沿用未签名构建流程，Windows 可能显示「未知发布者」或 SmartScreen 提示。
- 升级不会删除用户的提供商、API Key、远端共享配置或历史使用量数据。
- QQ 远程助手已移除；升级后如需继续在手机上使用，请在「微信连接」页扫码登录。微信登录凭据需要重新获取，旧 QQ 令牌与 NapCat 配置不会迁移。
