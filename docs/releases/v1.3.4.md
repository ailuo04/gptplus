# gpt++ v1.3.4

## 更新内容

### 新增：对等模型共享与远端同步

- 可选择发布本机启用的模型，通过独立的客户端授权令牌让另一台 gpt++ 使用。
- 支持添加远端共享端，自动同步远端模型清单；远端模型默认停用，本机可以独立启用、隐藏、恢复、排序和修改显示名。
- 共享端与接收端使用独立授权，远端凭据通过 Windows 系统安全存储保护；远端连接要求 HTTPS，本机回环地址可用于测试。
- 远端请求经过本机网关转发，保留流式响应、超时和断开传播；不会把远端模型写回本地提供商配置。

### 新增：提供商配置安全导入/导出

- 支持导出和导入字段级加密的提供商配置文件，API Key、请求头等敏感字段不会以明文落盘。
- 支持文件选择和拖拽导入，导入前展示脱敏预览；同名提供商覆盖必须再次确认。
- 导入使用事务流程，校验或注入失败时回滚现有配置；保留提供商卡片上的 API Key 复制入口。

### 新增：QQ 远程助手

- 通过 OneBot 11 / NapCat 接收 Codex 任务完成、失败和进度通知。
- 主人 QQ 可远程查看模型、启动多轮问答、插入后续要求、停止任务和续跑任务；支持图片消息转为模型图片输入。
- QQ 页面支持一键安装 QQ 与 NapCat、自动写入配置、拉起登录和二维码扫码登录；已登录账号可快速登录。
- 新增任务中心，统一跟踪桌面端会话与 `codex exec` 任务，避免 QQ 对话被误判成 Codex 任务。

### 安全性与网关改进

- 对网关日志、错误信息和远端同步日志统一脱敏，避免 API Key、授权令牌和私有请求头回显。
- 扩展 Responses 网关的共享端路由、请求超时、客户端断开处理和 Token/缓存 usage 记录。
- 主页增加对等共享入口；底部状态栏增加最近请求的 `tok/s`、缓存命中率和估算上下文占用提示。

## 验证

- 全量 Node 测试：336 项通过、0 项失败、1 项按真实用户配置条件跳过。
- Electron 冒烟渲染通过，主页及底部状态栏无运行期错误；QQ 远程交互由自动化测试覆盖。
- Windows x64 NSIS 未签名构建通过；Release 会同时上传安装器、`blockmap` 和 `latest.yml`。

## 安装与升级

- Release 提供 Windows x64 NSIS 安装器、差分更新 `blockmap` 和自动更新元数据 `latest.yml`。
- 本版本沿用未签名构建流程，Windows 可能显示「未知发布者」或 SmartScreen 提示。
- 升级不会删除用户的提供商、API Key、远端连接、QQ 配置或历史使用量数据。
