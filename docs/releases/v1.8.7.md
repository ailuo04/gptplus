# gpt++ v1.8.7

## 软件内更新摘要

- 语音输入新增「千问实时识别」，说话时在 ChatGPT 输入框显示临时字幕，停录后原位定稿。原有麦克风按钮、长按快捷键和本地离线模式保留。
- 支持 `paraformer-realtime-v2`（16 kHz）和 `fun-asr-flash-8k-realtime`（8 kHz）。使用千问 MaaS 地址和自己的 API Key；Key 仅加密保存在本机。已配置实时识别时，切换模型无需重新填 Key。

## 安装与升级

- 在「插件市场 → 语音输入 → 配置」选择「千问实时识别」，再选择 `paraformer-realtime-v2`。录音音频会发送给千问，调用按账号额度或价格计费。
- Windows x64 未签名安装包，附带差分更新文件和自动更新元数据。Windows 可能提示未知发布者。
