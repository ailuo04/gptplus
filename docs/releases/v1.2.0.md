# gpt++ v1.2.0

## 更新内容

### 使用量统计修复

- 修复左侧「使用量」数字与概览「请求数」不一致的问题，两处改为共用同一套请求统计逻辑。
- 已结束的成功、失败和客户端中断请求均参与计数，不再漏掉没有返回 Token 数据的请求；请求中间事件不重复计数。
- 切换「全部历史」「最近 24 小时」「最近 7 天」时，侧栏和概览使用相同的时间范围。
- 新请求结束后实时同步侧栏计数；每分钟刷新时也重新计算时间范围，避免没有新增请求时统计停留在旧值。

### 开机自启动增强

- 新增启动目标选择：可以仅启动 gpt++，也可以同时启动 gpt++ 和 ChatGPT。
- 保存启动目标偏好，在 Windows 登录自动启动时按选择执行；手动打开 gpt++ 不会因此额外拉起 ChatGPT。
- 启动 ChatGPT 时不主动结束已有客户端进程。

## 验证

- 全量 Node 测试：181 项通过、0 项失败、1 项真实用户配置条件测试跳过。
- 使用量回归测试覆盖失败及中断请求、无 Token 请求、时间范围切换、旧日志兼容和空数据。
- 真实 Electron 窗口验证：侧栏与概览计数一致，时间范围切换和无 Token 失败请求实时更新正常。

## 安装与升级

- Release 提供 Windows x64 NSIS 安装器、差分更新 blockmap 和自动更新元数据 `latest.yml`。
- 使用仓库现有的未签名构建流程，Windows 可能显示「未知发布者」或 SmartScreen 提示。
- 本次不修改或清空历史使用量数据；覆盖安装保留用户配置、提供商和 API Key。
