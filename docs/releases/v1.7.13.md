# gpt++ v1.7.13

## 软件内更新摘要

- 语音输入默认快捷键改为 Alt，支持在设置中自定义组合键；按住开始录音，松开结束。
- 调整实时识别预览和停顿断句，降低预览等待并减少短句。

## 详细说明

- 默认快捷键仅在 ChatGPT 输入框聚焦时生效；快捷键录音会持续到松开时结束。
- 可在语音输入设置中录制组合键并恢复默认 Alt；麦克风按钮与输入框鼠标长按入口保留。
- 本地实时识别在约 500 ms 连续语音后提供预览；将逗号断句停顿调整为约 650 ms、句末停顿调整为约 1.2 秒，并合并极短片段。
- 本地连续录音保留 10 分钟安全上限；提供商整段转写模式保持原有录音上限与行为。

## 安装与升级

- Release 提供 Windows x64 NSIS 安装包、差分更新 blockmap 和自动更新元数据 `latest.yml`。
- 本次沿用项目现有未签名发行流程；安装器和主程序没有 Authenticode 签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。
- 保留已有提供商、API Key、模型、插件配置和使用记录。

## 验证

- 全量 Node 测试：568 项，566 项通过、2 项环境跳过、0 项失败。
- Windows x64 未签名 NSIS 安装包构建通过（92,351,078 字节）；blockmap 已生成，`latest.yml` 中的文件大小与 SHA-512 均和安装包一致。
- 麦克风实际拾音仍需人工验收；自动化覆盖快捷键、实时字幕、分句写入、回滚和系统音频回环路径。
