# gpt++ v1.7.2

## 软件内更新摘要

- 自定义生图配置可在保存、启用前验证：使用当前填写的地址、Key、模型和生成参数，不要求本地网关运行。
- 生图 API 地址缺少协议或版本段时自动补全，已有版本路径和完整生图接口地址保留。
- 验证明确显示等待、成功及失败状态；验证期间修改表单会提示重新验证，避免混淆结果。

## 详细说明

- 「生成 1 张验证（可能计费）」使用当前表单中的配置向生图服务发起一次实际生成请求，不自动保存配置、启用插件或修改技能设置。已有 Key 时留空复用已保存的 Key，首次使用需填写 Key。
- 验证和正式生图共用执行器和网络代理设置；验证只返回结果，不保存测试图片。验证成功仅表示该次接口请求成功，不保证 ChatGPT 会自动选择该技能，也不验证网关链路。
- API URL 缺少协议或版本段时，验证和保存自动补齐 https:// 和 /v1；已带版本段的地址及完整 /images/generations 端点不会重复补全。
- 配置完成并验证通过后仍需手动保存并启用插件；通过技能生成时 gpt++ 和本地网关仍需运行。

## 安装与使用提示

- 本次发布沿用未签名 Windows x64 安装包，Windows 可能提示未知发布者或触发 SmartScreen。
- 生图接口测试可能计费；本次开发验证使用隔离本地模拟服务，没有调用真实付费接口。
