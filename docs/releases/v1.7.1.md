# gpt++ v1.7.1

## 软件内更新摘要

- 插件市场新增「自定义生图」：配置自己的 API URL、API Key 和模型，安装配套技能并可设为自动优先。
- 可保存图片尺寸、画面比例、画质和背景默认值；对话中的明确要求仅覆盖本次生图，不修改默认值或影响后续请求。
- API Key 使用本机系统安全存储加密；生图执行器固定使用已保存的服务，失败不切换提供商。
- 启用前备份技能配置；停用或卸载时禁用自定义技能并撤回内置技能开关，保留服务设置。

## 详细说明

### 自定义生图插件

- 在「插件市场 → 自定义生图」安装并配置你的 API URL、API Key 和生图模型。支持 OpenAI 兼容 `POST /images/generations`，可填写 Base URL 或完整端点。
- 插件默认未安装、未启用。启用后安装 `gptplus-imagegen` 技能，勾选「设为默认生图（自动优先）」时，通过 Codex 的技能配置停用已知内置 `imagegen` 技能；不删除内置文件。启用后请重启 ChatGPT 并开启新对话。
- 自动优先不等于强制接管：没有关闭底层生图工具，也不保证模型每次都会自动选择。需要明确选中时可使用 `$gptplus-imagegen`。
- 首版支持文生图，不支持编辑已有图片；执行时 gpt++ 与本地网关需保持运行。配套脚本使用 Python 3 标准库，可使用客户端自带的运行时，不自动安装依赖。

### 默认参数与单次覆盖

- 尺寸：1K / 2K / 4K；按长边 1024 / 2048 / 4096 px 换算并在界面显示实际宽高。
- 比例：1:1 / 4:3 / 3:4 / 16:9 / 9:16。
- 画质：低 / 中 / 高 / 自动。
- 背景：自动 / 不透明 / 透明；透明背景使用 PNG。
- 未在本次请求明确指定的字段沿用保存值；本次明确要求仅覆盖该次请求，不写回默认设置，不影响其他对话、后续或并发生成。只有当前请求明确要求复用上次参数时，技能才引用前次设置。
- 具体尺寸、画质和透明背景是否可用取决于服务及模型。上游不支持时明确报错，不自动降级、更换参数或切换提供商。

### 凭据与配置保护

- API URL / Key 沿用应用现有的系统安全存储；公开插件状态和事件不返回明文 Key，技能、命令和日志不写入 Key。
- 技能只通过需网关令牌认证的本地专用接口执行生图；调用方不能覆盖服务地址、Key 或模型。图片 URL 下载不携带 API Key。
- 启用及默认优先变更前备份 Codex 配置；保存失败回退本次技能和配置写入。外部修改过的技能文件或受管理配置块不会被强行覆盖。
- 配置页「生成 1 张验证（可能计费）」会实际调用一次生图服务，仅返回验证结果、不保存测试图；普通保存、启用和应用启动不会发起生图请求。

## 安装与使用提示

- 本次发布沿用未签名 Windows x64 安装包，Windows 可能显示未知发布者或 SmartScreen 提示。
- 升级后在插件市场按需安装、配置并启用自定义生图；原有提供商和其他插件设置保持不变。
- 尚未用真实第三方 API Key 验证所有提供商的参数兼容性，也未将技能自动选择描述为强保证。
