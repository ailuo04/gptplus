# gpt++ v1.6.3

## 更新内容

### 新增：语音输入可配置空格长按时长

- 插件市场的语音输入配置新增「空格长按时长」，可设置 `0.3` 到 `5` 秒，默认从原来的 `1.5` 秒调整为 `1` 秒。
- 长按空格开始录音的触发时长、麦克风提示文案和进度环动画会跟随当前配置，不再写死为固定时长。
- 设置会随插件配置保存在本机；旧配置没有该字段时自动使用 `1` 秒，无需手动迁移。

### 改进：微信连接入口归入插件市场

- 侧栏不再单独显示「微信连接」，避免与插件市场重复。
- 微信连接改为从插件市场中对应卡片的「配置」进入；进入配置页后，插件市场继续保持导航高亮。
- 微信连接页新增「返回插件市场」按钮，扫码登录、连接设置和运行状态管理保持原样。

## 兼容性

- 提供商、API Key、注入状态、用量历史和其他插件配置无需迁移。
- 已有语音输入插件配置会自动补齐默认长按时长；自定义长按时长从下次加载插件配置时生效。
- 微信连接凭据、联系人白名单、工作目录和 Codex 会话映射不变。

## 验证

- 全量 Node 测试：351 项，350 项通过，1 项按真实 Codex 配置条件跳过，0 项失败。
- Electron 隔离冒烟测试：插件市场可正常渲染，侧栏不再包含微信连接入口，微信卡片配置入口和返回导航通过渲染测试。
- GitHub Actions 会在标签推送后构建 Windows x64 未签名安装包、差分更新文件和 `latest.yml` 并创建 Release。
