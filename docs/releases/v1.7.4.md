# gpt++ v1.7.4

## 软件内更新摘要

- 中转站余额圆环固定在左侧设置入口上方，可拖动到合适位置并记住位置；双击恢复默认。
- 余额最多显示两位小数；读取中或刷新失败时，继续显示该提供商上一次成功读取值，并标注更新时间。
- 详情可通过点击圆环或页面空白处关闭；刷新按钮不会再误关详情。
- 未关联当前模型时仍明确显示感叹号，不使用其他提供商的余额冒充当前上游。

## 详细说明

### 中转站余额显示

- 圆环采用空心描边样式，默认位于左侧导航栏底部个人资料/设置入口上方。拖动圆环可自行调整位置，位置保存在当前 ChatGPT 页面；双击圆环恢复默认位置。
- 金额按实际读取精度保存，展示时最多保留两位小数。小于 0.01 的非零余额显示为 `<0.01`，不误显示为零；货币符号、分组和单位仍沿用上游明确信息。
- 当前模型对应提供商暂时尚未返回、刷新失败或遇到限流时，圆环优先显示该提供商上一次成功读取的余额，不再临时变成省略号或感叹号。详情标注“显示上一次读取值”和上次读取时间；本次失败原因仍会单独提示。
- 上次余额只按提供商保存展示所需的余额、币种、单位、时间和标识，不保存 API Key、Authorization、请求头或上游完整响应。
- 点击圆环打开余额详情；点击详情内“刷新”只触发刷新，不关闭详情；点击详情外任意页面位置关闭详情。
- 当前模型没有精确关联的上游时，圆环仍显示红色感叹号，不会使用其他提供商的缓存值代替。

### 升级说明

- 原有提供商、API Key、模型、注入状态、插件配置和使用记录保持不变。
- 本次发布沿用现有 Windows x64 未签名安装包流程，Windows 可能提示未知发布者或触发 SmartScreen。
- 更新后如仍看到旧版圆环，请通过 gpt++ 重启 ChatGPT 客户端，以重新注入页面脚本。
