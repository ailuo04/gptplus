# gpt++ v1.0.0

## 更新内容

- 新增使用量页「清空细数据」功能：清除请求明细、按模型/提供商统计、概览数据和运行日志，同时保留 Token 使用趋势。
- 新增使用量页「全部清空」功能：删除请求明细、运行日志和 Token 使用趋势聚合数据。
- 两种清空操作都增加二次确认，避免误操作；清空后会自动刷新统计页和日志状态。
- Token 使用趋势改为独立按天持久化，细数据清空后趋势仍可跨应用重启保留。
- 补充数据层和渲染层回归测试，覆盖两种清空模式、趋势保留和页面操作入口。

## 验证

- 全量测试：173 项，172 项通过，1 项按现有真实配置条件跳过，0 项失败。
- 渲染层测试：58 项全部通过。
- Electron 使用量页冒烟启动与桌面渲染验证通过。
- GitHub Actions 将在推送 `v1.0.0` 标签后构建 Windows 安装包并创建 Release。
