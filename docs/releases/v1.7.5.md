# gpt++ v1.7.5

## 软件内更新摘要

- 修复长按空格时输入框累积空格；短按只插入一个空格，长按启动语音录制。
- 支持在 ChatGPT 输入框内未选中文字的位置长按鼠标左键启动语音；松开鼠标停止录音。
- 页面失焦、切换窗口、选中文本或拖动选区时不会误触发语音输入。

## 详细说明

- 空格和鼠标共用插件设置中的长按时长。
- 普通鼠标点击继续用于定位光标；右键、中键、输入框外的鼠标操作保持原有行为。
- 窗口失焦或页面隐藏时会取消待触发或正在进行的语音录音。
