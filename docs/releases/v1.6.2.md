# gpt++ v1.6.2

## 更新内容

### 新增：页面内语音输入（本地 SenseVoice）

- 输入框的模型选择器与发送键之间新增麦克风按钮。录音条是浮在输入框上方的白色卡片，带实时波形、计时、停止/重试/取消，不再调起 Windows 系统听写浮层，也不会把模型选择器挤开。
- 默认使用本机 SenseVoice 离线识别，支持中、英、日、韩、粤语和自动检测。首次使用会下载约 231 MB 模型并做 SHA-256 校验；如果检测到 DeepSeek Harness 的语音模型缓存，会直接复用，不重复下载。
- 新增长按空格说话：在输入框内或页面空白处长按空格 1.5 秒开始录音，松开自动转写并插入光标处。按住期间麦克风按钮显示进度环，按出来的空格会被自动清掉；Esc 可取消。
- 输入法组词时不会误触发；切换窗口或页面隐藏会取消本次录音。
- 插件设置可在三种输入方式间切换：本地识别、提供商转写（OpenAI 兼容 `/audio/transcriptions`）、Windows 系统听写。

### 修复

- 修复长按空格被页面内部焦点变化打断的问题：现在只有真正的窗口失焦才会取消长按。
- 静音不再显示红色错误，改为中性的「未识别到语音」。
- 录音条改为绝对定位悬浮在输入框上方，不参与输入区布局。

## 兼容性

- 提供商、API Key、注入状态、用量历史和已有插件配置无需迁移。
- 语音输入默认使用本地识别；从未使用过语音输入的用户会在第一次录音时才准备模型。
- 录音和识别都在本机完成，音频不会上传；选择「提供商转写」时才会发送到所配置的提供商。

## 验证

- 全量 Node 测试：351 项，350 项通过，1 项按真实用户配置条件跳过，0 项失败。
- 用 Windows 真实按键事件验证：按住空格 1.5 秒进入录音，松开后自动转写并清理按出的空格；页面内部失焦不再中断录音。
- GitHub Actions 会在标签推送后构建 Windows x64 未签名安装包并创建 Release。
