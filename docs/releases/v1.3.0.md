# gpt++ v1.3.0

## 更新内容

### 新增：主页，把「提供商 → 本地网关 → ChatGPT」摊开在首屏

打开 gpt++ 先看到的是一张接线图，而不是提供商表单：

- **三段链路节点**：提供商（几个渠道、多少个模型，其中多少已停用）、本地网关（是否启用、是否在监听、端口与地址）、ChatGPT 客户端（已注入多少个模型）。每段单独着色，中间用带电流动效的连接线串起来；三段都通才显示「链路畅通」，否则是「等待接通」或「尚未配置」。
- **下一步只给一件事**：链路没通时，底部黄色提示条只列出当前该做的那一步——添加提供商、启用网关、启动网关、启用模型、注入模型，或重启客户端——并带一个直接执行它的按钮。链路已通就整条消失，不占版面。
- **首屏直接注入开关**：第三个节点上就是注入开关，不必先跳去模型页。
- **重启 ChatGPT 两段式确认**：首屏的「重启 ChatGPT」第一次点击只切成「确认重启？」，6 秒内再点一次才真正结束进程；页面重绘后确认态自动作废，不会在新的按钮上误触发。
- **最近请求与今日流量**：左侧列出最近 5 条网关完成记录（时间、模型、耗时、HTTP 状态），右侧是今日 Token 总量、请求数、成功率、平均耗时，外加最近 7 天用量柱状图。数据口径与使用量页完全一致，只统计已终结的请求，不把中间日志算进去。
- **提供商清单与快捷入口**：最多展示 4 个提供商（名称、Base URL、启用模型数，可单条编辑）；快捷入口提供复制网关地址、打开 Codex 配置目录、管理注入模型、网关与端口设置。

主页已成为默认打开的视图，侧栏图标上有一个状态点：三段全通为实心，链路部分就绪为半亮。

### 新增：单独删除某个模型

模型表的操作列此前的唯一用途是拖动调序，现在多了一个常驻可见的删除按钮（垃圾桶图标）：

- 点击后弹出确认框，逐条说明影响：哪些地方会变、它是不是当前默认模型、是否会让提供商清空、删除后只能重新添加模型 ID 恢复。
- 删除时同步清理 `modelOrder` 里对应的键，不会留下指向不存在模型的陈旧排序条目；如果它正是默认模型，默认值一并清空，交给注入流程重新选。
- **删掉最后一个启用模型时自动还原官方模型**：目录会变空，客户端遇到空目录会静默回退，注入也必然失败；所以此时不是回滚删除，而是关闭注入、清掉目录路径，把 ChatGPT 还原成官方模型，并提示用户。
- 注入开启时删除会改写目录与 Codex 配置，因此会标记「需要重启」。
- 失败时整体回滚配置，并尽量把注入状态恢复到删除前。

### 新增：删除提供商改为弹窗二次确认

原先删除提供商是在卡片底部内联展开一行「确认删除？」，容易在密集的卡片列表里点错。现在改成独立弹窗，明确写出：它的几个模型会一起删除、多少启用模型会从 ChatGPT 清单移除、当前注入状态下的后果（包括「这是最后一个提供商」），以及恢复需要重新填写 Base URL 与 API Key。

### 界面：视觉刷新

以「精密工作台」为目标做了一轮收敛，不改任何业务行为：

- **弹窗改用毛玻璃面板**：半透明表面 + 背景模糊，头部与底部条单独一档底色，宽度按用途分档（删除确认 430px、模型测试 580px、一般表单 620px），出现与关闭的动效分别重做。
- **关闭弹窗不再瞬间消失**：补充了缩回动画时长常量，节点等动画播完再移除；打开另一个弹窗时不再把焦点抢回旧位置。
- **修复主按钮禁用态文字消失**：通用禁用样式会把背景回落成中性面板色，而主按钮的文字色是近白色，悬停时整块看不见。主按钮现在单独覆盖这条回落。
- **模型测试弹窗、使用量弹窗、设置页提示条**等一并对齐新的间距、圆角与字号档位。

## 验证

- 全量 Node 测试：245 项、0 项失败、1 项跳过（跳过项为真实 `config.toml` 处于注入状态的用例）。
- 新增用例覆盖：主页渲染与导航一致性、模型删除（清理排序键、清空失效默认模型、删最后一个模型时还原官方模型、provider/model 不存在的报错）、模型页写操作同步刷新提供商快照、禁用主按钮悬停颜色。
- 真实渲染层验证（`tools/verify-hero-next.cjs`，双主题）：提示条尺寸、文字与按钮对比度（浅色 6.03:1、深色 8.81:1）、两段式确认只触发一次重启、重启成功后提示条消失、失败后提示条保留且按钮可再次点击。
- 启动页 UI 验证脚本已扩展到主页，覆盖 `1440x900` 与 `940x620` 两档宽度的标题与布局。

## 安装与升级

- Release 提供 Windows x64 NSIS 安装器、差分更新 blockmap 和自动更新元数据 `latest.yml`。
- 沿用仓库现有未签名构建流程，Windows 可能显示"未知发布者"或 SmartScreen 提示。
- 升级不清空用户配置、提供商、API Key 或历史使用量数据。
- 已安装的 gpt++ 会在启动约 8 秒后检查 GitHub Release，发现新版本仅弹窗提示，不会自动下载。
