# gpt++ v1.2.3

## 更新内容

### 修复开机自启动后 ChatGPT 只在后台运行

- 修复 Windows 上误用 macOS 专属登录状态字段，导致跳过 ChatGPT 联动启动的问题。
- 为 Windows 登录项添加明确的自启动参数，正确区分开机登录与普通手动启动。
- 选择「gpt++ + ChatGPT」时，通过 Windows 已注册的应用入口激活 ChatGPT 主窗口，兼容客户端已经在后台运行的情况，不结束已有 ChatGPT 进程。
- 保留网关启动检查完成后再唤起客户端的顺序，避免客户端过早连接尚未就绪的本地网关。

### 兼容旧设置并提高启动可靠性

- 自动迁移已启用的旧版登录项，保留「仅 gpt++」或「gpt++ + ChatGPT」的原有选择，无需重新设置。
- 尊重任务管理器中禁用的启动项，不会因迁移而擅自重新启用。
- 支持登录请求被已有 gpt++ 实例接收的情况；重复登录启动请求不会重复拉起 ChatGPT。
- 手动指定的非应用包安装路径仍可直接启动；应用信息发现失败或系统激活进程无法启动时回退到可执行文件启动方式。
- 捕获异步进程启动错误，避免启动失败却记录为成功。

- 补充自启动识别、启动目标控制、旧登录项迁移、系统应用激活、错误处理与启动回退的行为回归测试。
- Windows 真机模拟登录启动：确认实际前台进程为 ChatGPT，主窗口可见且未最小化。
- 重复发送登录启动请求：确认未重复拉起客户端。
