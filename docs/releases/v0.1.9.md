# gpt++ v0.1.9

## 更新内容

- 优化模型列表拖动排序：拖动行会根据实际重叠进度连续让位，减少整行突然跳动。
- 修复拖动目标判断：以被拖行中心点越过相邻行中线作为换位边界，支持不同抓取位置和上下方向。
- 修复快速松手时的排序丢失：释放指针时立即同步最终坐标，再提交完整的新顺序。
- 保存排序成功后直接同步当前列表和内存状态，避免整页刷新造成闪烁；保存失败时才恢复页面数据。
- 增加指针捕获、取消事件清理和拖动动画回收，避免重复监听与残留状态。
- 增加模型拖动排序的单元测试，覆盖目标判断、连续让位、DOM 顺序和保存失败恢复。
