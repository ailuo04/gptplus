# gpt++ v1.7.9

## 软件内更新摘要

- 点击一次“立即更新”即可自动下载安装并重新打开 gpt++，无需再操作安装向导。
- 用量信息栏紧凑显示生成速度、缓存命中率、上下文和余额，窄窗口自动换行。
- 阶段扣费以红色数字悬浮弹出，约两秒后收回，四项信息的位置保持不动。

## 详细说明

- 下载完成和继续安装共用安装前权限复查、重复点击保护与静默安装路径；启动安装器失败时恢复退出标记并显示错误。
- 新安装器收到旧客户端的更新参数时也会自动进入静默模式，兼容 v1.7.8 等旧版未传 `/S` 的更新。手动打开安装包仍保留目录选择。
- 信息栏按内容排列并缩小项目间距，补充上下文和余额标签，保留原有数据计算与可选额度功能。
- 阶段扣费提示使用独立悬浮层，带弹出和收回动画，不参与四项信息的布局。靠近窗口边缘时自动避让，窗口缩放或滚动后跟随余额定位；停用插件时清理悬浮层和监听器。
- 保留安装目录可写检查、已有提供商、API Key、模型、插件配置和使用记录。

## 安装与升级

- Release 提供 Windows x64 NSIS 安装包、差分更新 blockmap 和自动更新元数据 `latest.yml`。
- 沿用项目现有未签名发行流程，安装器和主程序没有 Authenticode 签名。
- 自动检查仍只提示新版本，用户点击“立即更新”后才开始下载和安装。

## 验证

- 全量 Node 测试 519 项：517 项通过，2 项按本机配置条件跳过，0 项失败。
- 真实 Chromium 56 组布局检查通过，覆盖浅深主题、宽窄窗口、长金额、额度开关、悬浮弹出与收回；提示出现和消失前后四项信息的坐标及尺寸一致。
- 独立 NSIS 测试实际编译并执行安装器初始化钩子，确认旧版更新参数自动进入静默模式，手动安装保留交互模式；测试不执行覆盖安装。
- Windows x64 未签名 NSIS 安装包本地构建通过。
