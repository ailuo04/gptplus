# gpt++ v0.2.2

## 更新内容

- 新增“查看历史版本”功能，可从 GitHub Release 列出可用的较早稳定版本。
- 新增指定版本回退，下载前校验版本、安装器和 `latest.yml`，确认后自动下载并重启安装。
- 回退复用现有更新流程和签名校验，只替换程序文件，不删除本地提供商、API Key、网关和其他配置。
- 更新页增加回退版本选择、加载状态、风险提示和错误反馈；主进程、IPC 与 preload API 完成对应接线。
- 增加历史版本筛选、版本比较、回退下载与渲染层入口测试，并同步补充 README 使用说明。

## 验证

- 全量测试：167 项，166 项通过，1 项按现有真实配置条件跳过，0 项失败。
- GitHub Actions 会在推送 `v0.2.2` 标签后构建 Windows 安装包并发布 GitHub Release。
