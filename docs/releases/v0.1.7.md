# gpt++ v0.1.7

## 更新内容

- 修复页面过渡动画重复渲染导致的卡顿和双重闪烁。
- 已预渲染的页面不再在过渡结束后重复清空并重建 DOM。
- 入场动画改为在隐藏页面图层中提前启动，避免内容出现后又闪回透明首帧。
- 增加回归测试，覆盖预渲染页面的单次渲染和入场动画时序。

## 验证

- 全量测试：162 项，161 项通过，1 项按现有真实配置条件跳过。
- Electron 冒烟测试通过，模型页无渲染错误且布局正常。

## 安装包

GitHub Actions 会自动构建 Windows 安装包，并将安装器、差分 blockmap 和 `latest.yml` 上传到本次 Release。
