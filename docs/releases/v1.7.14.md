# gpt++ v1.7.14

## 软件内更新摘要

- 重新整理语音输入设置层级，并让下拉选项跟随应用主题。

## 详细说明

- 设置按「输入方式、录音触发、识别设置」分区排列，快捷键与识别选项更易查找。
- 识别方式、提供商和语言选择统一使用应用内主题化下拉菜单，避免系统原生弹层与界面主题不一致。
- 修复主题化下拉选择后，当前选项标签与已选状态未同步更新的问题；所选引擎、提供商和语言会正确保存。

## 安装与升级

- Release 提供 Windows x64 NSIS 安装包、差分更新 blockmap 和自动更新元数据 `latest.yml`。
- 沿用项目现有未签名发行流程；安装器和主程序没有 Authenticode 签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。
- 保留已有提供商、API Key、模型、插件配置和使用记录。
