# gpt++ v1.6.4

## 更新内容

### 改进：首次更新检查提前到启动后 20 秒

- 已安装版本启动后，首次检查 GitHub Release 的等待时间由 2 分钟缩短为 20 秒。
- 设置页的自动检查说明同步改为“启动后 20 秒首次检查”，避免界面与真实调度时间不一致。
- 首次检查完成后的周期检查逻辑保持不变，仍按用户设置的 `updates.checkIntervalMinutes` 执行，默认 60 分钟；手动检查仍然立即执行。

## 兼容性

- 提供商、API Key、模型、注入状态、用量历史和插件配置无需迁移。
- 自动更新仍然只查询版本，不会自动下载或安装；发现新版本后仍需用户确认。
- 开发模式、冒烟测试和未打包运行继续禁用自动更新检查。

## 验证

- 全量 Node 测试：351 项，350 项通过，1 项按真实 Codex 配置条件跳过，0 项失败。
- 更新调度测试确认首次等待为 20 秒，后续仍按配置的分钟间隔检查。
- 设置页测试确认展示“启动后 20 秒首次检查”。
- GitHub Actions 会在标签推送后构建 Windows x64 未签名安装包、差分更新文件和 `latest.yml` 并创建 Release。
