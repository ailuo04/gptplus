# gpt++ v1.1.0

## 更新内容

- 左侧底部新增 Windows 开机自启动开关，标题和开关保持在同一排；切换后即时显示系统实际状态。
- 提供商的「测试连接」支持选择一个或多个模型，并逐个调用实际生成接口，显示每个模型的 HTTP 状态、响应延时和失败原因。
- 按 OpenAI 兼容、Responses、Anthropic 协议构造对应的模型测试请求；未配置模型时仍可测试 `/models` 连通性。
- 修复系统代理测试请求的 fetch 与代理 dispatcher 不兼容问题。
- 修复 HTTP 请求已返回成功状态、但响应正文读取超时时被误判为成功或响应格式错误的问题。
- 补充开机自启动、按模型测试、协议适配、代理请求和响应正文超时的回归测试。

## 验证

- 全量 Node 测试通过；1 项真实用户配置条件测试跳过。
- 真实客户端注入/还原端到端检查与模型选择器检查通过。
- Electron 桌面端启动和界面渲染冒烟检查通过。
- GitHub Actions 会在推送 `v1.1.0` 标签后构建 Windows 安装包并创建 Release。

## 安装包

本次 GitHub Actions 使用未签名 Windows 安装包；Windows 可能显示未知发布者提示。Release 会包含 NSIS 安装器、差分 blockmap 和 `latest.yml`。
