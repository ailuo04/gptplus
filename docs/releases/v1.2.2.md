# gpt++ v1.2.2

## 更新内容

### 修复开机自启动目标切换

- 修复选择「gpt++ + ChatGPT」后，无法切回「仅 gpt++」的问题。
- 启动目标支持双向切换，界面选中状态与实际保存的设置保持一致。
- 关闭再开启自启动时保留已选择的启动目标；重复点击当前目标不会重复保存。

### 优化底部状态栏

- 固定状态圆点的尺寸，防止在紧凑布局中被挤压。
- 移除状态圆点的阴影和动画，避免光晕被裁切或遮挡相邻文字。
- 保留网关、注入状态及原有语义色，适配浅色和深色主题。

## 验证

- 全量 Node 测试：182 项通过、0 项失败，1 项真实用户配置条件测试跳过。
- 真实 Electron 自启动组件验收：11 组布局与状态检查，覆盖目标双向切换、关闭再开启保留目标、保存锁定、失败回退与键盘操作。
- 状态栏在浅色、深色主题及 1440×900、940×620 窗口下通过圆点裁切、文字重叠与溢出检查。
- 补充 390×844 自启动组件验收与状态栏观察；完整桌面窗口仍以 940×620 为最小支持尺寸。
- 验收使用隔离示例数据，不修改真实 Windows 自启动设置。

## 安装与升级

- Release 提供 Windows x64 NSIS 安装器、差分更新 blockmap 和自动更新元数据 `latest.yml`。
- 沿用仓库现有未签名构建流程，Windows 可能显示「未知发布者」或 SmartScreen 提示。
- 本次补丁不清空用户配置、提供商、API Key 或历史使用量数据。
