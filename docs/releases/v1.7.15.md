# gpt++ v1.7.15

## 软件内更新摘要

- 修复 Codex 写入独立设置后，自定义生图配置可能无法保存的问题。
- 提高语音输入设置中当前快捷键和「恢复 Alt」按钮的区分度。

## 详细说明

- 当 Codex 把 `[tui]` 等独立设置写进生图技能块时，gpt++ 会先校验原有技能内容，再备份并恢复配置边界，保留新写入的设置。原有生图技能内容确实被改动时，仍会停止写入。
- 当前录音快捷键使用实心主题色，「恢复 Alt」使用中性描边。样式适配浅色和深色主题。

## 安装与升级

- 提供 Windows x64 NSIS 安装包、差分更新文件和自动更新元数据 `latest.yml`。
- Windows 安装包沿用项目现有的未签名发布流程。
