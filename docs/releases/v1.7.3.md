# gpt++ v1.7.3

## 软件内更新摘要

- 新增「中转站余额」插件，支持 Sub2API 与 New API。
- ChatGPT 设置入口上方显示当前模型对应上游的具体余额；切换模型后自动跟随切换。
- 圆环显示余额变化动画；刷新时在圆环上方短暂显示本次可比较的区间消费。
- 支持自定义刷新间隔，默认每 60 秒刷新一次；余额查询只使用只读 GET 请求，不发送聊天或生成请求。

## 详细说明

- 在「插件市场」安装并启用「中转站余额」，选择已有提供商和对应的 Sub2API / New API 适配器。
- 余额沿用已保存的提供商 API Key、代理和安全自定义请求头；密钥不会注入 ChatGPT 页面或余额快照。
- 当前模型没有精确关联的上游时，圆环显示红色感叹号；点击圆环可查看已关联提供商的余额详情并手动刷新。
- 只有上游返回可比较的累计用量时才显示精确区间消费；仅有余额变化时不会伪造消费金额。
- New API 无法确定币种换算比例时保留原始额度单位；余额按 API Key 范围统计，可能包含其他客户端或会话的消耗。

## 安装与使用提示

- 本次发布使用未签名 Windows x64 安装包，Windows 可能提示未知发布者或触发 SmartScreen。
- 安装后在插件市场安装并启用「中转站余额」，完成提供商关联后重启 ChatGPT 客户端即可。
