# gpt++ v1.6.1

## 更新内容

### 改进：最近请求的思考强度改为独立列并显示英文档位

- 主页「最近请求」中，思考强度不再挂在渠道名下面，而是放在模型/渠道与耗时之间的独立一列，耗时与状态列因此保持对齐。
- 档位标签统一为英文 `EFFORT`，值直接使用上游的英文档位：`off`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`、`ultra`。
- 请求没有显式档位时显示 `default`；升级前的旧记录没有档位字段，保持空白，不猜测补值。
- 悬停提示同步改为英文，展示实际发给上游的档位；ChatGPT 请求值与上游值不同时会一并标出原始请求值。

## 兼容性

- 提供商、API Key、注入状态、用量历史和插件配置无需迁移。
- 只调整主页最近请求的展示；网关请求和上游档位选择逻辑不变，历史记录保持原样。
