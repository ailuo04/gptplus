# gpt++ v1.6.9

## 软件内更新摘要

- 修复开机自启动时 ChatGPT 已在运行、但未携带 CDP 调试端口，导致用量信息栏不显示的问题。
- 用量信息栏启用时，登录启动会确保 ChatGPT 带 CDP 启动并立即注入速度、缓存命中率和上下文占用。
- 未启用用量信息栏插件的常规开机启动不受影响，不会额外重启 ChatGPT。

## 更新内容

### 修复：开机自启动后用量信息栏缺失

- 开机自启动且「ChatGPT 用量信息栏」启用时，改为先结束可能已经运行、但没有 CDP 调试端口的 ChatGPT 实例，再通过 gpt++ 的启动包装器重新启动。
- 新实例会携带 `--remote-debugging-port` 启动，随后立即注入速度、缓存命中率和上下文占用，不再需要用户手动点击「重启 ChatGPT 客户端」。
- 无论登录时 ChatGPT 尚未启动，还是已经被系统或用户提前打开，都会确保最终运行的是可供状态栏注入的实例。
- 用量信息栏未启用时继续使用普通应用入口激活，不会因为本次修复而主动结束 ChatGPT。

## 兼容性

- 提供商、API Key、模型、注入状态、用量历史和插件配置无需迁移。
- 手动「重启 ChatGPT 客户端」、模型选择器和网关转发行为不变。
- GitHub Release 继续提供 Windows x64 NSIS 安装器、差分 `blockmap` 和 `latest.yml` 更新元数据。
