# gpt++ v1.6.6

## 软件内更新摘要

- 修复用量状态栏吐字速度，避免缓冲流出现上千 `tok/s` 的错误结果。
- 请求完成后立即刷新速度、缓存和上下文，不再等待 rollout 文件落盘。
- 完善 Chat、Anthropic、Responses 三协议的 Usage 统计和缺失数据估算。
- 状态栏不再因数据过期或无对话变灰，浅色主题固定为纯黑不透明文字。

## 更新内容

### 修复：平均生成速度使用完整上游请求耗时

- 旧算法使用首个流片段到结束的时间作为分母。部分中转会缓冲内容并在接近结束时一次性下发，导致输出 Token 不变而分母极短，速度可能错误放大到上千 `tok/s`。
- 现在统一使用“输出 Token / 完整上游请求耗时”，覆盖 Chat Completions、Anthropic Messages 和 Responses 协议。
- 界面名称改为“平均生成速度”，明确包含思考阶段和首字等待时间。

### 改进：用量三项数据完成即刷新

- 网关请求完成后会主动唤醒状态栏推送，不再等待 Codex 写入最新的 `token_count`。
- 最近请求快照按会话单独保留，不会被高频日志挤出 200 条环形缓存。
- rollout 文件暂时不可读时仍会先显示网关已经返回的速度和 Token 数据，后续再合并上下文窗口。
- 页面可见时的定时刷新间隔缩短到 500ms，后台轮询最长 1 秒；正常请求完成事件通常可在几十毫秒内触发刷新。

### 修复：三协议 Token、缓存和上下文统计

- 兼容更多缓存字段别名，并修正上游 `total_tokens` 小于输入与输出之和的情况。
- rollout 缺少 `total_tokens` 时使用输入与输出 Token 推导上下文占用。
- 上游没有返回缓存字段时显示未知，不再伪报为 `0.0%`。
- Usage 缺失时的估算改为 CJK/emoji 约 1 Token、普通文字约 4 字符 1 Token，并纳入思考、正文、工具名称和参数。
- 状态栏只在对应的数据项上标注“估算”，不会因为一个估算值隐藏其他可靠数据。

### 修复：状态栏无对话或数据过期时不变暗

- 移除旧的过期淡化和半透明主题色。
- 浅色主题固定使用纯黑 `#000`，深色主题使用页面主文字色，所有文本和图标保持 `opacity: 1`。
- 没有对话或暂时没有新数据时只显示占位符，不降低文字亮度。

## 兼容性

- 提供商、API Key、模型、注入状态、用量历史和插件配置无需迁移。
- 所有模型与三类入站、三类上游协议继续使用同一套 Usage 归一化与状态栏展示逻辑。
- GitHub Release 继续提供 Windows x64 NSIS 安装器、差分 `blockmap` 和 `latest.yml` 更新元数据。
