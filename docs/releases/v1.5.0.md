# gpt++ v1.5.0

## 更新内容

### 新增：便携式提供商配置导入/导出

- 提供商配置改为整体 AES-256-GCM 加密，名称、模型、Base URL、API Key、自定义请求头、模型顺序和默认模型都不再直接写入导出文件。
- 配置文件不绑定当前 Windows 用户，可在安装兼容版本的 gpt++ 的其他电脑导入；不需要额外设置文件密码。
- 导入前仍会进行扩展名、大小、结构、认证标签和字段校验，并通过预览确认新增、改名新增、覆盖或跳过。
- 支持把 `.gptplus-providers` 文件拖到窗口任意位置导入，点击选择、主页拖放区和窗口级拖放共用同一套预览流程。
- 保留提供商卡片上的 API Key 显示/隐藏和复制入口。

### 新增：自动更新检查间隔

- 应用启动后等待 2 分钟再进行首次更新检查，避免启动阶段立即访问网络。
- 后续自动检查间隔可在设置页配置，范围为 5-1440 分钟，默认 60 分钟，并持久化到本地配置。
- 自动检查只查询版本，不会自动下载或安装；发现新版本后仍需用户确认。
- 修复了开发模式、冒烟模式、未打包运行和 Linux 禁用自动更新时，保存检查间隔后界面状态回退的问题。

### 改进：ChatGPT 用量信息栏

- 调整用量信息栏的文字、图标和过期状态显示，使不同主题下的对比度和状态反馈更稳定。

### 工程与验证

- 补充便携配置、窗口级拖放、自动更新调度和禁用模式状态同步的回归覆盖。
- 修复 Windows NSIS 未签名构建使用系统临时目录导致的中间安装器失败；构建时使用仓库内短临时路径，避免生成可运行的残缺安装器。
- 清理不再需要的临时逆向/探针脚本和旧版发布检查文档，固定验证夹具移入 `test/fixtures/`。

## 兼容性与安全说明

- 提供商传输文件格式升级为 v4；v3 及更早版本的导出文件不兼容，升级前请重新导出或保留原应用版本。
- 便携密钥随应用发布，主要用于防止导出文件被直接查看；不能防止能够分析已安装应用程序的人取得导出文件中的 API Key。
- 升级不会删除本机提供商、API Key、网关、远端共享和用量历史配置。

## 验证

- 全量 Node 测试：317 项通过，1 项按真实用户配置条件跳过，0 项失败。
- Electron 冒烟测试：窗口启动成功，`errors=0`。
- Windows x64 目录打包验证通过；GitHub Actions 会在标签推送后生成 NSIS 安装器、`blockmap` 和 `latest.yml` 并创建 Release。
