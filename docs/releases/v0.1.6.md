# gpt++ v0.1.6

## 更新内容

- 恢复 `0.1.4` 版本的页面过渡动画：切换页面时，内容区会从下方淡入，并按区块顺序错开出现。
- 优化切页加载体验：新页面在数据加载期间显示轻量占位内容，数据加载与页面过渡并行进行，减少点击后的空白等待。
- 优化异步切页安全性：快速连续切换页面时，旧页面的异步加载结果不会覆盖当前页面。
- 优化动画性能：页面过渡期间只临时提升页面图层，长内容和表格行不再常驻 GPU 图层。
- 增加渲染层测试，覆盖页面过渡、占位内容和动画触发类清理逻辑。

## 验证

- 全量测试：160 项通过，1 项跳过，0 项失败。
- Electron 冒烟测试通过，首屏和页面布局正常渲染。

## 安装包

GitHub Actions 会自动构建 Windows 安装包，并将安装器、差分 blockmap 和 `latest.yml` 上传到本次 Release。
