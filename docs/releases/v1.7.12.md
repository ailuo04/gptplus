# gpt++ v1.7.12

## 软件内更新摘要

- 本地语音输入支持实时字幕和逐句写入，按停顿补充标点，并改善长语音分段。
- Windows 单击麦克风按钮可转写系统播放声音；长按空格或鼠标仍使用麦克风录音。

## 详细说明

- 本地 SenseVoice 识别改为分块流式处理，稳定分句即时写入输入框，未定稿内容显示为字幕。
- 根据停顿时长决定逗号、句号等标点；长语音在低能量位置软切分，避免固定时长截断。
- Windows 系统声音由 gpt++ 隐藏采集窗口进行回环捕获，不占用麦克风；取消时只回滚本次录入内容。
- OpenAI 兼容提供商的 `/audio/transcriptions` 模式保持整段转写，现有插件配置格式不变。

## 安装与升级

- Release 提供 Windows x64 NSIS 安装包、差分更新 blockmap 和自动更新元数据 `latest.yml`。
- 沿用项目现有未签名发行流程，安装器和主程序没有 Authenticode 签名。

## 验证

- 语音相关单测：60 项通过，0 项失败。
- 全量 Node 测试：562 项，560 项通过、2 项环境跳过、0 项失败。
- 麦克风实际拾音仍需人工验收；已有自动化覆盖麦克风录音逻辑及系统音频回环路径。
