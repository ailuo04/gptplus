# gpt++ v1.6.14

## 软件内更新摘要

- 保留 Codex 原始 User-Agent，上游请求不再被默认的 undici 标识替代；提供商自定义请求头仍优先。
- 修复生成速度计时与显示，使用单调时钟、保留一位小数，不再把估算 Token 或工具调用间隔当作真实生成速度。
- 修复缓存命中率统计，区分未返回数据与明确的零命中，排除无效计数并按有效输入 Token 加权。
- 用量信息栏优先推送刚完成请求的数据，避免等待会话记录读取或混用相邻请求的指标。

## 详细说明

### 上游客户端标识

- 将客户端实际发送的 User-Agent 传递给上游，保留真实客户端类型、版本和系统信息，不硬编码 Codex 版本。
- 覆盖 Responses、Chat Completions、Anthropic Messages 三种上游协议，以及流式、非流式、兼容重试、瞬时错误重试和对等网关链路。
- 提供商手动配置的 User-Agent 大小写无关地优先生效；不透传客户端凭据或其它私有请求头。

### 速度与缓存统计

- 生成耗时使用单调时钟，避免系统时钟调整造成速率失真。
- 生成速度统一保留一位小数；上游未返回真实 usage、缺少有效首包时间等情况下显示不可用，不伪造精确速率。
- 缓存写入不再被当作缓存命中依据，未知数据与明确的零命中分别处理；矛盾或无效计数不进入命中率汇总。
- 用量页显示有效缓存样本数；状态栏更快接收刚完成请求的数据，并防止相邻请求错配。

## 使用说明

- 更新 gpt++ 后，新经过网关的 Codex 请求使用修复后的客户端标识。若提供商手动配置了 User-Agent，仍以手动配置为准。
- 本次发布沿用未签名 Windows x64 安装包，Windows 可能显示未知发布者或 SmartScreen 提示。
