# gpt++ v0.1.8

## 更新内容

- 简化页面切换：移除双层路由、占位骨架和分层入场动画。
- 切页后立即渲染当前缓存状态，只播放一次 120ms 的轻量淡入。
- 数据加载改为后台刷新，不再先显示空白或等待数据后才出现页面。
- 缓存数据已完整的页面不再因为异步检查而重复重绘。
- 增加回归测试，确保切页不创建占位层，也不会重复刷新当前页面。

## 验证

- 全量测试：161 项，160 项通过，1 项按现有真实配置条件跳过。
- Electron 冒烟测试通过，使用量页和模型页均无渲染错误、无空白页面。

## 安装包

GitHub Actions 会自动构建 Windows 安装包，并将安装器、差分 blockmap 和 `latest.yml` 上传到本次 Release。
