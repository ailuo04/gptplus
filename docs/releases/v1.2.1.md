# gpt++ v1.2.1

## 更新内容

### 窄窗口布局优化

- 修复侧栏「上游网络」及网络模式按钮被挤压换行的问题。
- 优化模型页三段连接链路，最小窗口下完整显示关键注入状态。
- 简化底部状态栏，优先保留网关运行状态、端口与注入数量，减少文字截断。
- 使用量指标在窄窗口下改为上排三项、下排两项铺满，避免右侧空缺。
- 缩短模型表头为「模型 ID」，完整含义保留在悬停提示中。

### 统一界面视觉

- 开机自启动卡片改为标题与开关同排，启动模式左右等宽，各占一半。
- 统一提供商、模型与设置页开关为绿色开启态、白色滑块与一致尺寸。
- 统一主要卡片和输入框圆角，减弱阴影、发光和悬停浮起效果。
- 输入框与选择器去掉凹陷阴影，提升浅色与深色主题的一致性。
- 提高深色主题辅助文字可读性，使用固定字号保持窗口缩放时的稳定性。

### 信息精简

- 网关与注入状态集中在底栏，移除侧栏重复状态框。
- 精简模型与设置页说明文字，模型配置细节支持按需展开。
- 保留配置生效所需的客户端重启提示及上下文能力限制说明。

## 验证

- 全量 Node 测试：181 项通过、0 项失败、1 项真实用户配置条件测试跳过。
- 真实 Electron 自启动组件验收：10 组布局与状态检查，覆盖等宽、文字溢出、开关、保存锁定、失败回退与键盘操作。
- 四个主要页面、浅色与深色主题、1440×900 与 940×620 窗口共 16 组渲染检查。
- 使用隔离示例数据生成实际页面截图，长页面分段检查，不修改真实 Windows 自启动设置。

## 安装与升级

- Release 提供 Windows x64 NSIS 安装器、差分更新 blockmap 和自动更新元数据 `latest.yml`。
- 沿用仓库现有未签名构建流程，Windows 可能显示「未知发布者」或 SmartScreen 提示。
- 本次为界面优化，不清空用户配置、提供商、API Key 或历史使用量数据。
