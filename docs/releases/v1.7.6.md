# gpt++ v1.7.6

## 软件内更新摘要

- 中转站余额圆环按剩余额度比例显示，低于 20% 转黄、低于 5% 转红。
- 鼠标悬浮圆环查看余额、累计消耗和最近一次消耗；支持在 ChatGPT 可视范围内拖动。
- 红色消费金额提示完整限制在 ChatGPT 可视范围内。

## 详细说明

- 比例使用 `1 - 消耗值 / (消耗值 + 余额)`；缺少可信累计消耗值或单位不一致时不伪造进度。
- 圆环详情悬浮弹出、移开收起；圆环与详情之间移动时保持展开。
- 拖动位置限制在 ChatGPT `visualViewport` 内并记住位置，双击恢复默认位置。
- 红色消费提示在视口四边内完整显示；页面运行时升级会清理旧版圆环和样式。
- 保留 v1.7.5 的空格和鼠标长按语音录制行为及配置。

## 升级说明

- 原有提供商、API Key、模型、插件配置和使用记录保持不变。
- 本次沿用 GitHub Actions 的 Windows x64 未签名安装包流程；Windows 可能显示未知发布者或 SmartScreen 提示。
