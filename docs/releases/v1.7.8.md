# gpt++ v1.7.8

## 软件内更新摘要

- 修复开机启动时 ChatGPT 插件注入失败，并让 ChatGPT 更早启动。
- 最近请求和使用记录中的 HTTP 状态都可查看紧凑的中文说明。

## 详细说明

- 启用页面插件时，ChatGPT 启动会携带 CDP 调试端口；ChatGPT 进程启动后即继续后台准备插件，不再等待本地网关和页面注入完成。
- 后台按用量信息栏、额度显示、语音输入的顺序恢复插件；单项恢复失败不会阻止其他插件。
- 已运行的 ChatGPT 优先复用现有 CDP 端口；没有调试端口时才重新启动以启用注入。
- 修复 MSIX 启动代理传递调试参数的引号，并修复用量状态栏注入余额配置的问题。
- 首页最近请求和使用记录共享同一状态说明；提示框按内容收窄、减少留白，并支持悬停和键盘聚焦。

## 升级说明
