# gpt++ v1.3.3

## 更新内容

### 改进：更新弹窗收窄为紧凑毛玻璃卡片

上一版把更新弹窗从默认 620px 收到 440px，但实际打开时仍然偏高、偏空：标题区、提示块、按钮区各占一条横带，中间那条琥珀色提示条又厚又实，看起来更像一块面板而不是一张浮在界面上的玻璃卡。这次按「刚刚好」重做：

- **尺寸收紧**：弹窗从 440×218 收到 384×177，宽度约减 13%、高度约减 19%；提示文案保持单行，不再出现大片留白。
- **结构合并**：去掉标题区和按钮区的分隔带，三段收成一张完整卡片；标题左侧加入 30px 琥珀下载图标，当前版本与最新版本压在标题下方，信息层次更清楚。
- **提示条减重**：内边距和行高收紧，琥珀底从 14% 降到 8%～9%，只保留左侧强调边和图标；正文文案缩短为一行，不再抢走玻璃面板的质感。
- **操作区右对齐**：按钮高度 30px，「暂不更新」在左、「立即更新」在右，符合常见确认弹窗的操作习惯。
- **毛玻璃质感**：新增更新弹窗专用的薄玻璃令牌，浅色与深色主题独立配色；面板使用 56%～58% 半透明底色、38px 背景模糊、170% 饱和度、150° 斜向高光和 1px 高光描边。遮罩同时降低不透明度、加深模糊，让背后的界面真正透出来，而不是简单盖一层灰。
- **状态不跳动**：「立即更新」后切换到「正在下载」状态时复用同一套布局，弹窗高度保持 177.4px，按钮替换为「后台下载」，进度文案就地更新。

## 验证

- 全量 Node 测试：246 项、0 项失败、1 项跳过（跳过项为真实 `config.toml` 处于注入状态的用例）。
- 真实渲染层探针（隐藏窗口 + `capturePage`）分别截图核对浅色、深色与下载中三种状态：弹窗尺寸 384×177.4，标题、版本号、提示文案均无换行或溢出，按钮右对齐，无渲染错误。
- 「发现新版本 → 正在下载」状态切换后弹窗高度不变，避免进度更新时界面抖动。

## 安装与升级

- Release 提供 Windows x64 NSIS 安装器、差分更新 blockmap 和自动更新元数据 `latest.yml`。
- 沿用仓库现有未签名构建流程，Windows 可能显示「未知发布者」或 SmartScreen 提示。
- 升级不清空用户配置、提供商、API Key 或历史使用量数据。
