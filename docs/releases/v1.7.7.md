# gpt++ v1.7.7

## 软件内更新摘要

- 将中转站额度整合进 ChatGPT 用量信息栏，并迁移旧额度插件配置。
- 最近请求的 HTTP 状态支持悬浮查看中文正常说明或错误可能原因。
- 刷新消耗在余额右侧短暂显示，保留三位小数。

## 详细说明

- 用量信息栏第四项可显示当前模型对应供应商的额度；余额前仅显示圆形 `$` 图标，数字不带货币前缀。
- 两次额度刷新间的消耗以红色三位小数显示在余额右侧，约两秒后自动收回，不推动其余信息项。
- 悬停或键盘聚焦最近请求的 HTTP 状态时显示简短提示。成功状态说明请求正常；常见错误状态给出中文可能原因，未知状态引导查看完整错误详情。
- 错误提示依据 HTTP 状态码提供一般性判断，不替代上游返回的具体错误信息。
- 旧版「中转站余额」供应商映射和刷新间隔会迁移到「ChatGPT 用量信息栏」配置。
